# 🌊 kurobbs-wiki — 鳴潮 WIKI ちびアシスタント

> 🌍 **Read this in** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.md)

こんにちは、ようこそ 🌸 これは**あなたの AI チャットの中に住んでいるちびアシスタント**です。コマンドを覚える必要も、技術に詳しくなる必要も、何かをインストールする必要もありません。**普段メッセージを送るように、気になることをそのまま話すだけ**で、調べて、まとめて、かんたんに説明してくれます。

特に**鳴潮（Wuthering Waves）を遊んでいるお友達**のために作りました。キャラを育てるのにどう組めばいいか分からない？お気に入りのキャラに合ういい構成を知りたい？パーティ構成のアイデアがいくつか欲しい？自分のアカウントにどんなキャラがいるか見たい？——**そういう時、もういちいちページを開いて攻略を探したりメモを取ったりする必要はありません**。そのまま話しかけるだけで OK です。

---

## 🧠 普段、どんな風に手伝ってくれるの

使い方はとっても簡単。まるで仲良しのお友達にメッセージを送るみたいです。例えば、こんな風に言うと：

> 「スイスイのエコーは何を装備すればいいかな？武器はどれがいい？」

自動で代わりに走り回って、こんな風に一歩ずつ進めてくれます：

1. 🧭 まず、あなたが何を聞きたいのかを理解します（装備？編成？それとも他？）
2. 🔎 こっそり WIKI を開いて「スイスイ」の資料を探します
3. 📖 エコー・武器・突破素材などのポイントをひとつずつピックアップ
4. 💬 分かりやすい言葉にまとめて返してくれます。しかもページのリンク付きなので、詳しく見たければそこからどうぞ

最初から最後まで、あなたはこの一言を言うだけで OK。あとは全部おまかせです。

## 💬 こんな風にそのまま聞いてみて

> 下の例はどれも「こう言う → 代わりにこうしてくれる → こういうものが手に入る」と書いてあります。そのまま使ってもいいし、気になるキャラに置き換えても大丈夫です。

### 🎀 お気に入りのキャラに装備をセッティング

**こう言ってみて：**
> スイスイが大好き！彼女のエコーは何を装備すればいい？武器はどれがいいかな？

**代わりにこうしてくれる：** スイスイの資料を探して、エコー・武器・突破素材をピックアップし、ひとつの言葉にまとめて説明してくれます。

**手に入るもの：** はっきり分かるおすすめの装備 + 対応するページのリンク。詳しく見たければそこからどうぞ。

### 🤝 持っているキャラでパーティを組む

**こう言ってみて：**
> ロゼリア、今汐、秧秧を持ってるんだけど、パーティを組んでほしいな。うちのスイスイをメインにしたいの〜

**代わりにこうしてくれる：** 持っているキャラをひとつひとつ試しながら組み合わせを考えて、いちばん合う構成を選んでくれます。しかも、それぞれの組み合わせがどこがいいのかも教えてくれます。

**手に入るもの：** おすすめのパーティをいくつか + それぞれの理由。参考になる攻略も添えてくれます。

### 🎯 もっとこだわったパーティが欲しい

**こう言ってみて：**
> 緋雪でパーティを組んでほしいな。攻略をいくつか参考にして見て

**代わりにこうしてくれる：** もっと細かく見てくれます——ルールに沿ってキャラを選ぶだけじゃなく、何人かがどう組み合わせると動かしやすいかまで比べて、あなたに合ったパーティを組んでくれます。

**手に入るもの：** 並べ替え済みのパーティリスト。それぞれに「どうしてこの組み合わせなのか」の理由付きです。

### 📖 攻略の画像 / 動画が分からない？

**こう言ってみて：**
> このキャラの攻略画像、いったい何が書いてあるの？教えてくれない？

**代わりにこうしてくれる：** 攻略の画像や動画の中身を見て、編成・エコー・操作のコツなどのポイントを文字にまとめて説明してくれます。

**手に入るもの：** 分かりやすい攻略の要約。自分で画像をじーっと見て推測する必要はもうありません。

### 👤 自分のアカウントのキャラを見る

**こう言ってみて：**
> 私のアカウントにどんなキャラがいるか見て、パーティを組んでくれない？

**代わりにこうしてくれる：** ブラウザで自分のクルミナルストリートのアカウントに一度だけログインするように案内してくれます（電話番号と認証コードを入れるだけ）。それから**あなたが本当に持っているキャラだけ**でパーティを組んでくれます。

**手に入るもの：** あなたのアカウントに完全に基づいたパーティのおすすめ。さらに「どのキャラを引くか / 育てるといいか」も教えてくれます。

> ✅ **安心してね：** 最初の 4 つ（攻略を調べる・パーティを組む・画像を見る）は**ログイン一切不要**で、誰でもすぐ使えます。ログインが必要なのは最後の「マイアカウント」だけ。しかもあなたのデータは自分のパソコンの中にだけ保存されて、どこにも勝手に送られません。

| やりたいこと | こう言ってみて | 代わりにこうしてくれる |
|-----------|-------------|--------|
| 📖 キャラの攻略を調べる | 「スイスイの武器は何がいい？」 | 資料を調べて、まとめて教えてくれる |
| 🗂️ どんな内容があるか見る | 「ゲームのキャラはどんな種類に分かれてる？」 | 目次を開いてリストアップしてくれる |

## 🔐 プライバシーについて、安心してね

> ひとつだけ気をつけてほしいところがあります——このアシスタントには、あなたのアカウントのデータを読み取る機能がひとつあります。ここでちゃんと説明しますね 👇

- **攻略を調べる・パーティを組む・画像を見る**（上の 4 つ）→ すべて公開されている情報を使います。**ログイン不要**で、あなたの個人情報には一切関わりません。
- **「マイアカウント」機能**（自分のキャラを見る・それでパーティを組む）→ ブラウザで自分のクルミナルストリートのアカウントに一度だけログインする必要があります。ログイン後の情報は**あなたのパソコンの中にだけ保存**されます：
  - あなたのログイン情報 + キャラリスト
  - 各キャラの解放状況・武器・エコー・レベルなど
- **これらのデータはこのパソコンのみに保存され、どのサーバーにもアップロードされません。** ログイン情報は約 45 分で自動的に期限切れになり、その時はもう一度ログインするようにお知らせしてくれます。
- ログインしていない時にあなたのアカウントのキャラを勝手にでっち上げることは**ありません**し、あなたのアカウント情報を第三者に送ることも**ありません**。

**もしログインしたくない場合**：最初の 4 つ（攻略を調べる / パーティを組む / 画像を見る）だけでも十分に使えます。「マイアカウント」はまったく使わなくて大丈夫です。

## 📦 あなたの AI に入れたい？（これはインストールを手伝ってくれる人向け）

> もしあなたが**ふつうのプレイヤー**で、ただ使いたいだけなら——この部分は**完全に読み飛ばして OK** です。周りに詳しいお友達（またはお使いの AI ツールの説明）に一度だけ入れてもらえば、**入れた後は何もする必要はありません**。上の聞き方でそのまま使うだけです。

<details>
<summary>👉 タップしてインストール手順を見る（手伝ってくれる人向け）</summary>

**方法 1：ローカルでインストール**

リポジトリの中の `kurobbs-wiki/` フォルダを、AI ツールの skills / スキル ディレクトリ（Claude Code、Cursor、Copilot などに対応）に置いてください。そして、このフォルダがどこにあるのかをプログラムに教えます：

```bash
# Windows の場合：
set SKILL_DIR=D:\tools\kurobbs-wiki

# macOS / Linux の場合：
export SKILL_DIR=~/tools/kurobbs-wiki
```

**方法 2：用意されたインストールコマンドを使う**

```bash
npx skills add Alphamancer/kurobbs-wiki
```

**あらかじめ入れておくもの：**

- **Python 3.8+**（ふつうのパソコンならもう入っているかもしれません）
- **Playwright**（「攻略の画像 / 動画を見る」機能のときだけ必要）
  ```bash
  pip install playwright && playwright install chromium
  ```
- **ffmpeg**（任意、動画をダウンロードするときだけ使います）

> 💡 **ちいさなヒント：** 細かい指示（何という名前か、どう調べるか、どうパーティを組むか）は、スキルに付属の「使い方マニュアル」に書いてあります。AI が入れた後で自分でその通りにやってくれるので、人が覚える必要はありません。

</details>

## ⚔️ 終焉マトリクスのパーティ編成（手動メンテナンスのルール集）

これだけは**手動で入力したルール**に頼っている機能です。情報の鮮度にご注意ください 👇

- **ルールは自動取得ではありません**：終焉マトリクスは期ごとに敵の編成・報酬のライン・共鳴回路・強化キャラのリストがすべて違い、ゲーム内から読み取れる公開 API もありません。これらのルールはすべてメンテナーが**手作業でまとめたもの**で、`references/endstate-matrix.md` に保存されています。
- **期ごとのメンテナンスが必要**：ゲームが新しいマトリクス期に更新されるたびに、このファイル内の敵の耐性・星声のライン・強化リスト・スコア換算などを手動で確認・更新する必要があります。**ファイル冒頭に記載されたデータの日付は、その期にのみ有効です。**
- **おすすめの使い方**：この機能を使う前に、`references/endstate-matrix.md` の冒頭に書かれた日付をチェックしてください。ゲームのバージョン 1 つ分以上更新が空いている場合、パーティ提案が古いルールで計算されている可能性があります。ゲーム内の実際の内容を優先するか、メンテナーに更新を促してください。
- その他の機能（攻略検索・育成・ふつうのパーティ編成・画像の解読）はこの影響を受けません。リアルタイムの WIKI データを読み込んでいます。

## ⚠️ たまにある小さなトラブル

- **たまに新しい内容が見つからない？** ゲームの更新で新しいイベントやコンテンツが増えるので、自動で更新して探し直します。少し待っていれば大丈夫です。
- **たまにエラーになる？** データの出どころがたまに変わることがありますが、自動でリトライするので、だいたい自分で回復します。
