# 🌊 kurobbs-wiki — 명조(鸣潮) WIKI 도우미

> 🌍 **Read this in** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.md)

안녕하세요, 환영해요 🌸 이건 **여러분의 AI 채팅창 안에 살고 있는 작은 도우미**예요 — 명령어를 외울 필요도, 기술을 알 필요도, 뭔가를 설치할 필요도 전혀 없어요. **평소에 메시지 보내듯이, 궁금한 걸 그냥 말하면** 도와주는 친구가 찾아서 정리해 주고, 쉽고 편하게 설명해 줘요.

특히 **명조(Wuthering Waves)를 즐기는 친구들**을 위해 준비했어요: 캐릭터 키우는데 장비를 어떻게 맞춰야 할지 모르겠다? 좋아하는 캐릭터에게 딱 맞는 세팅을 해주고 싶다? 팀 조합 아이디어가 몇 개 필요하다? 심지어 내 계정에 어떤 캐릭터가 있는지 보고 싶다? — **이런 것들을 이제 하나하나 웹페이지 뒤지고 공략 메모하면서 정리할 필요가 없어요**, 그냥 바로 물어보면 돼요.

---

## 🧠 평소에 어떻게 도와주는지

사용법은 정말 간단해요. 좋은 친구한테 메시지 보내는 것과 똑같아요. 예를 들어 이렇게 말해 보세요:

> 「수이수이(穗穗) 음향기(声骸)는 뭘 끼워야 좋을까? 무기는 어떤 걸 골라야 해?」

그러면 도우미가 알아서 발로 뛰어서, 한 단계씩 이렇게 진행해요:

1. 🧭 먼저 뭘 물어보는지 잘 알아듣고 (장비 세팅? 팀 조합? 아니면 다른 거?)
2. 🔎 조용히 WIKI에서 「수이수이」 정보를 찾아서
3. 📖 음향기, 무기, 돌파 재료 같은 핵심들을 하나씩 뽑아내고
4. 💬 알아듣기 쉽게 정리해서 답장을 보내주고, 웹페이지 링크도 같이 붙여줘서 더 자세히 보고 싶으면 눌러서 볼 수 있어요

처음부터 끝까지, 여러분은 이 한마디만 하면 돼요. 나머지는 전부 도우미가 알아서 해요.

## 💬 이렇게 그대로 물어보면 돼요

> 아래 예시들은 전부 「이렇게 말하면 → 도우미가 뭘 해주고 → 뭘 받게 되는지」로 표시해 뒀어요. 그대로 써도 되고, 궁금한 캐릭터로 바꿔서 물어봐도 돼요.

### 🎀 좋아하는 캐릭터 장비 세팅하기

**이렇게 물어보세요:**
> 나 수이수이 엄청 좋아해! 그녀 음향기는 뭘 입혀야 좋아? 무기는 뭘 끼워야 해?

**도우미가 해주는 것:** 수이수이 정보를 찾아서 음향기, 무기, 돌파 재료를 뽑아내고, 한마디로 정리해서 알려줘요.

**받게 되는 것:** 또렷하고 분명한 세팅 추천 + 해당 웹페이지 링크. 더 자세히 보고 싶으면 눌러서 볼 수 있어요.

### 🤝 내가 가진 캐릭터로 팀 꾸미기

**이렇게 물어보세요:**
> 나 로세라(洛瑟菈), 진시(今汐), 양양(秧秧)이 있어. 팀 좀 짜줘, 우리 수이수이를 메인으로 하고 싶어~

**도우미가 해주는 것:** 여러분이 가진 캐릭터들로 하나하나 조합을 시도해 보고, 가장 알맞은 구성을 골라서, 각 조합이 왜 좋은지도 알려줘요.

**받게 되는 것:** 추천 팀 몇 개 + 각 팀의 이유, 참고할 수 있는 공략도 같이 붙여줘요.

### 🎯 좀 더 깊이 있는 팀 조합 원할 때

**이렇게 물어보세요:**
> 페이쉐(绯雪)로 팀 좀 짜줘, 공략 여러 개 참고해서 봐줘

**도우미가 해주는 것:** 더 자세히 봐요 — 규칙대로 사람을 고르는 것뿐 아니라, 몇 명이 어떻게 호흡이 잘 맞는지 비교해서, 더 잘 맞는 팀으로 정리해 줘요.

**받게 되는 것:** 순서대로 정리된 팀 목록, 각각 왜 이렇게 맞췄는지 설명까지 받아요.

### 📖 공략 그림 / 영상이 이해 안 돼?

**이렇게 물어보세요:**
> 이 캐릭터 공략 그림은 도대체 뭐라고 하는 거야? 좀 설명해 줘

**도우미가 해주는 것:** 공략의 그림이나 영상 내용을 다 훑어보고, 팀 조합·음향기·조작 요령 같은 핵심들을 글로 정리해서 알려줘요.

**받게 되는 것:** 알아듣기 쉬운 공략 요약을 받아요. 굳이 그림만 뚫어지게 쳐다볼 필요 없어요.

### 👤 내 계정에 있는 캐릭터 보기

**이렇게 물어보세요:**
> 내 계정에 어떤 캐릭터가 있는지 봐줘, 팀 좀 짜줘

**도우미가 해주는 것:** 브라우저에서 내 쿠제구(库街区) 계정에 한 번 로그인하도록 안내해요 (휴대폰 번호와 인증번호만 입력하면 돼요). 그리고 **내가 진짜로 가진 캐릭터만 기준으로** 팀을 짜줘요.

**받게 되는 것:** 완전히 내 계정 기반의 팀 추천. 어떤 캐릭터를 뽑거나 키울 만한지 부족한 점도 알려줘요.

> ✅ **걱정 마세요, 걱정 마세요:** 앞의 4가지 (공략 보기, 팀 짜기, 그림 보기)는 **로그인 전혀 필요 없고**, 누구나 바로 쓸 수 있어요. 오직 마지막 「내 계정」만 로그인을 한 번 해야 하고, 내 정보는 내 컴퓨터에만 저장돼서 함부로 전송되지 않아요.

| 하고 싶은 것 | 이렇게 말하면 | 도우미가 해주는 것 |
|-----------|-------------|--------|
| 📖 캐릭터 공략 보기 | "수이수이 무기 뭘 끼워" | 자료 찾아서 정리해 줌 |
| 🗂️ 어떤 내용이 있는지 보기 | "게임에서 캐릭터는 몇 종류로 나뉘어" | 목차 뒤져서 목록으로 보여줌 |
| 🤝 팀 짜기 | "팀 좀 짜줘" | 내 캐릭터 분석해서 방안 제시 |
| 🎯 깊이 있는 팀 조합 | "페이쉐로 팀 짜줘, 공략 참고해" | 여러 개 비교해서 순서대로 정리 |
| 👤 내 계정 사용하기 | "내 계정엔 어떤 캐릭터 있어" | 로그인 후 진짜 가진 캐릭터만 기준으로 |
| 🖼️ 공략 그림 이해하기 | "이 공략 그림 뭐라 하는 거야" | 그림·영상 내용 보고 설명해 줌 |

## 🔐 내 프라이버시, 안심해도 돼요

> 딱 하나 주의할 점이 있어요 — 이 도우미에는 내 계정 데이터를 읽는 기능이 하나 있어요. 여기서 제대로 설명해 드릴게요 👇

- **공략 보기, 팀 짜기, 그림 보기** (위 4가지) → 전부 공개 자료만 사용해요. **로그인 필요 없고**, 내 개인정보도 전혀 안 걸쳐요.
- **「내 계정」 기능** (내 캐릭터가 뭔지 보고, 그걸로 팀 짜기) → 브라우저에서 내 쿠제구 계정에 한 번 로그인해야 해요. 로그인 후 이 정보들은 **내 컴퓨터에만 저장돼요**:
  - 내 로그인 자격 증명 + 캐릭터 목록
  - 각 캐릭터의 해금 상태, 무기, 음향기, 레벨 등
- **이 정보는 내 기기(로컬)에만 존재하고, 어떤 서버에도 업로드되지 않아요.** 로그인 자격 증명은 약 45분 후 자동으로 만료되고, 만료되면 다시 한 번 로그인하라고 알려줘요.
- 로그인 안 한 상태에서 내 계정 캐릭터를 지어내지 **않고**, 내 계정 정보를 어떤 제3자에게도 보내지 **않아요**.

**로그인을 아예 하고 싶지 않다면:** 앞의 4가지 (공략 보기 / 팀 짜기 / 그림 보기)만 써도 충분해요. 「내 계정」은 전혀 쓸 필요 없어요.

## 📦 내 AI에 설치하고 싶다면? (이 부분은 설치를 도와주는 사람용이에요)

> 만약 **일반 플레이어**라서 그냥 쓰고 싶은 것뿐이라면 — 이 부분은 **완전히 건너뛰어도 돼요**. 주변에 아는 친구 (또는 여러분이 보는 AI 도구 설명)에게 한 번만 설치를 부탁하면 돼요. **설치가 끝나면 아무것도 신경 쓸 필요 없고**, 위에 있는 물어보는 방식만 그대로 쓰면 돼요.

<details>
<summary>👉 눌러서 설치 방법 보기 (설치를 도와주는 사람용)</summary>

**방식 1: 로컬 설치**

저장소(repository)의 `kurobbs-wiki/` 폴더를, AI 도구의 skills / 스킬 디렉터리에 넣으세요 (Claude Code, Cursor, Copilot 등 전부 지원해요). 그리고 프로그램에 이 폴더가 어디 있는지 알려주면 돼요:

```bash
# Windows：
set SKILL_DIR=D:\tools\kurobbs-wiki

# macOS / Linux：
export SKILL_DIR=~/tools/kurobbs-wiki
```

**방식 2: 준비된 설치 명령어 사용하기**

```bash
npx skills add Alphamancer/kurobbs-wiki
```

**미리 설치해 둬야 하는 것들:**

- **Python 3.8+** (보통 컴퓨터에는 이미 있을 거예요)
- **Playwright** (「공략 그림 / 영상 보기」 기능에만 필요해요)
  ```bash
  pip install playwright && playwright install chromium
  ```
- **ffmpeg** (선택 사항, 영상 다운로드할 때만 사용해요)

> 💡 **꿀팁:** 그 구체적인 지시사항 (뭐라고 부르는지, 어떻게 검색하는지, 어떻게 팀을 짜는지)은 전부 스킬에 내장된 「사용 설명서」에 적혀 있어요. AI가 설치된 뒤 스스로 그대로 따라 하니까, 사람이 외울 필요가 없어요.

</details>

## ⚠️ 가끔 겪을 수 있는 작은 상황

- **가끔 새 내용이 안 잡힌다?** 게임 업데이트로 새 이벤트·새 내용이 추가되면, 도우미가 자동으로 새로고침해서 다시 찾아요. 잠깐만 기다리면 돼요.
- **가끔 오류가 난다?** 데이터 출처가 가끔 조정될 때가 있어요. 도우미가 자동으로 재시도하니까, 보통 알아서 회복돼요.
