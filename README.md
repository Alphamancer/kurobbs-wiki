# 🌊 kurobbs-wiki — 鸣潮 WIKI 小助手

> 🌍 **Read this in** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.md)

嗨，欢迎你来 🌸 这是一款**住在你 AI 聊天框里的小助手**——你不用记任何命令、不用懂任何技术、更不用装任何东西。**只要像平时发消息一样，把你想问的说出来**，它就会帮你查好、整理好、轻轻松松讲给你听。

特别为**玩鸣潮（Wuthering Waves）的朋友**准备：养角色不知道怎么配？想给喜欢的角色搭个好用的配置？想要几套配队思路？甚至看看自己号上有哪些角色——**这些都不用再一个个翻网页、刷攻略做笔记了**，直接开口问它就行。

---

## 🧠 它平时是怎么帮你的

用起来超简单，就像和好朋友发消息一样。比如你说：

> 「帮我看看穗穗的声骸带什么好？武器选哪把呀？」

它就会自动帮你跑腿，一步接一步：

1. 🧭 先听明白你想问什么（是配装？配队？还是别的？）
2. 🔎 悄悄去 WIKI 里翻到「穗穗」的资料
3. 📖 把声骸、武器、突破材料这些重点一条条挑出来
4. 💬 整理成一段好懂的话回给你，还附上网页链接，想细看再点进去

从头到尾，你只需要说这一句，剩下的它全包了。

## 💬 你可以直接照着这样问

> 下面每个例子都标了「你这样说 → 它替你做什么 → 你会得到什么」，都可以直接拿去用，或者换成你想问的角色哦。

### 🎀 给喜欢的角色配装

**你这样问：**
> 我超爱穗穗！她的声骸穿什么好？武器带哪把呀？

**它替你：** 找到穗穗的资料，把声骸、武器、突破材料挑出来，整理成一句话讲给你。

**你会得到：** 清清楚楚的搭配建议 + 对应网页链接，想细看再点进去。

### 🤝 用你手上的角色组队

**你这样问：**
> 我有洛瑟菈、今汐、秧秧，帮我配个队，想让我家穗穗当主力～

**它替你：** 按你手上这几个角色，一个个试着搭配，挑出最合适的组合，还告诉你每个组合好在哪。

**你会得到：** 几套推荐队伍 + 每套的理由，附上可以参考的攻略。

### 🎯 想要更讲究一点的配队

**你这样问：**
> 帮我用绯雪配队，多参考几篇攻略看看

**它替你：** 看得更细——不只按规则挑人，还会比较一下几个人怎么配合更顺手，帮你排出更适合你的队伍。

**你会得到：** 一份排好序的队伍清单，每条都说明为什么这么搭。

### 📖 看不懂攻略图 / 视频？

**你这样问：**
> 这张角色的攻略图到底讲了啥？帮我讲讲呗

**它替你：** 把攻略的图或视频内容看一遍，把配队、声骸、操作手法这些重点整理成文字讲给你。

**你会得到：** 一份好懂的攻略摘要，不用自己盯着图猜半天。

### 👤 看看自己账号里的角色

**你这样问：**
> 看看我号上有哪些角色，帮我配个队呗

**它替你：** 引导你在浏览器里登录一次你自己的库街区账号（填一下手机号和验证码就行），然后**只根据你真实拥有的角色**来组队。

**你会得到：** 完全基于你自己账号的配队建议，还会提醒你缺哪个值得抽或练。

> ✅ **放心放心：** 前面 4 种（查攻略、配队、看图）**完全不用登录**，谁都能直接用；只有最后「我的账号」才需要登录一次，而且你的资料只存在你自己电脑里，不会乱传。

## 🔐 关于你的隐私，可以放心

> 就一条要留意的地方——这个助手有一个功能会读到你的账号数据。这边好好给你说清楚 👇

- **查攻略、配队、看图**（上面 4 种）→ 全部用的公开资料，**不需要登录**，也不涉及你任何个人信息。
- **「我的账号」功能**（看自己有什么角色、用它配队）→ 需要你在浏览器里登录一次自己的库街区账号。登录后这些信息会**保存只在你自己电脑上**：
  - 你的登录凭证 + 角色列表
  - 每个角色的解锁状态、武器、声骸、等级等
- **这些资料只存在本机，不会上传到任何服务器。** 登录凭证大约 45 分钟会自动过期，过期后它会提醒你再登录一次。
- 它**不会**在你没登录的时候瞎编你的账号角色，也**不会**把你的账号资料发给任何第三方。

**如果你完全不想登录**：只用前面那 4 种（查攻略 / 配队 / 看图）就很够啦，完全用不到「我的账号」。

## 📦 想把它装进你的 AI？（这部分给帮忙安装的人看）

> 如果你是**普通玩家**，只是想用——那这部分你**可以完全跳过不看**。请身边懂一点的朋友（或者你看的 AI 工具说明）帮你装一次就行，**装好之后你什么都不用管**，直接用上面那些问法就好啦。

<details>
<summary>👉 点开看安装步骤（给帮忙安装的人）</summary>

**方式一：本地安装**

把仓库里的 `kurobbs-wiki/` 文件夹，放进 AI 工具的 skills / 技能 目录里（Claude Code、Cursor、Copilot 等都支持）。然后告诉程序这个文件夹在哪：

```bash
# Windows：
set SKILL_DIR=D:\tools\kurobbs-wiki

# macOS / Linux：
export SKILL_DIR=~/tools/kurobbs-wiki
```

**方式二：用现成的安装命令**

```bash
npx skills add Alphamancer/kurobbs-wiki
```

**需要提前装好的东西：**

- **Python 3.8+**（一般电脑可能已经有了）
- **Playwright**（只有「看攻略图 / 视频」这个功能需要）
  ```bash
  pip install playwright && playwright install chromium
  ```
- **ffmpeg**（可选，只有下载视频时才用）

> 💡 **小贴士：** 那些具体指令（叫什么、怎么查、怎么配队）都写在技能自带的「使用手册」里，AI 装好后会自己照着做，不用人去记。

</details>

## ⚠️ 你可能遇到的小情况

- **偶尔查不到新内容？** 游戏更新会加新活动、新内容，它会自动刷新重新找，等一下就好。
- **偶尔报错？** 数据来源偶尔会调整，它会自动重试，一般都能自己恢复。
